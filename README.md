# Dialogue 1.0

Create branching conversations in Unreal Engine with a tree editor and Blueprint controls. Choose separate progress for each player or shared progress, with an override on each speaker.

[Read the user guide](https://funbydefault.github.io/dialogue-docs/)

This first-release candidate is still undergoing compatibility and gameplay checks. See the guide for current limits and setup steps.
